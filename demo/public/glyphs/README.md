Glyph fixture for deterministic text rendering (no external font server).

- Font: Noto Sans Regular, range 0-255 only (Basic Latin + Latin-1). Labels in the demo must stay in that range.
- License: SIL Open Font License 1.1. The SDF PBF is a conversion of the font, a "Modified Version" in the OFL's terms,
  so it travels with the copyright notice and the license text: [`OFL.txt`](./OFL.txt). Noto has no Reserved Font Name.
- Copyright line in `OFL.txt`: the one Noto Sans ships today, taken from the `LICENSE` of the npm package
  `@fontsource/noto-sans` 5.3.0 (Google Fonts' `OFL.txt` for Noto Sans); the OFL text is that file's, unchanged.
  demotiles does not record which Noto Sans release its PBF was made from.
- Source of the prebuilt SDF PBF: https://github.com/maplibre/demotiles (font/Noto Sans Regular/0-255.pbf), fetched 2026-09-20.
